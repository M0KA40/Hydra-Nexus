# Security reports

Do not include credentials, account metadata, game saves or private notes in a public issue. Use the repository's private vulnerability reporting option if it is available. Otherwise open an issue containing only a short description and ask for a private reporting channel before sharing a working exploit or sensitive files.

Reports should identify the Nexus and Hydra versions, affected component, impact and a minimal reproduction. The current public release is the supported baseline; fixes may require updating the installed patch.
