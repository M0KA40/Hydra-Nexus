# Invisible Mode

Enable the plugin in Settings → Hydra Nexus → Plugins. Enabling it activates privacy immediately. The account menu then shows Invisible Mode below Friends, where you can turn privacy on or off without disabling the plugin.

Nexus keeps private activity local while retaining access to artwork and local progress. Disabling the plugin turns privacy off and hides the account-menu control. Turning privacy off does not automatically publish activity that was kept local; use Resume activity sharing only if you want Hydra to publish it. Presence updates can take time and game notifications depend on Hydra servers.

The control uses Hydra's native account menu and follows the selected theme and interface language. See [privacy](privacy.md) for data handling.
