# Legacy 2.3 compatibility

This source is based on 2.2, not the 3.0 runtime. Existing native features and settings are retained. `legacy-upgrade-ui.js` adds one theme-native sidebar card; the first-run localized notes provide the same direct download action. `downloadNewNexus` opens a fixed HTTPS GitHub EXE asset URL from the trusted main-process RPC. New Cloud/Activity code is not bundled here. Keep this branch separate from main. The shared Latest release has BAT version 2.3/revision 1 and EXE version 3.0 with an independent EXE metadata file.
