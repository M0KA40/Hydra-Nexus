# Hydra Nexus 2.2

Une interface repensée en bêta, au-delà des couleurs. Quiet Slate et Nexus Mint partagent la même disposition ; choisissez les cercles dans Paramètres → Thèmes. Le développement continuera.

Accueil propose un carrousel cinématographique et une découverte élargie avec données Steam et cache. Les pages réunissent Overview, Updates, About, Community et Details. Updates affiche les actualités et notes Steam dans un lecteur intégré. Les jeux hors bibliothèque ouvrent About.

Game Page Layout permet de choisir la visibilité et de réordonner les sections dans Plugins, sans perdre les champs ni les brouillons.

Correction des anciennes restrictions Invisible qui bloquaient l’activité du profil : les files natives reprennent automatiquement après mise à jour et restauration de session, en conservant présence invisible et anciennes captures protégées. Le programme de mise à jour réessaie les verrouillages temporaires du fichier exécutable dans un délai limité, avec récupération sûre.
