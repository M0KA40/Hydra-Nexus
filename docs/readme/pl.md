# Hydra Nexus 2.2

Przeprojektowany interfejs w wersji beta, więcej niż zmiana kolorów. Quiet Slate i Nexus Mint mają ten sam układ; wybierz kolorowe kółka w Ustawieniach → Motywy. Rozwój będzie kontynuowany.

Strona główna oferuje filmową karuzelę i rozszerzone odkrywanie z danymi Steam oraz pamięcią podręczną. Strony gier mają Overview, Updates, About, Community i Details. Updates pokazuje wiadomości i informacje o aktualizacjach Steam we wbudowanym czytniku. Gry spoza biblioteki otwierają About.

Game Page Layout pozwala ustawiać widoczność i kolejność sekcji w Plugins, zachowując pola i szkice.

Usunięto dawne ograniczenia Invisible blokujące aktywność profilu: po aktualizacji i przywróceniu sesji kolejki wznawiają się automatycznie. Niewidoczność i ochrona dawnych zrzutów pozostają zachowane. Aktualizator ponawia tymczasowe blokady pliku w ograniczonym czasie i zachowuje bezpieczne odzyskiwanie.
