# Hydra Nexus 1.2.01 — experimental theme update

This is experimental version 1.2.01. Final version 1.2.1 is planned after owner testing. The updater treats the final version as newer even though its numeric parts match this experimental label. This is a local testing candidate. It has not been published to GitHub or installed into a live Hydra application by this task.

- Fix unreadable text in Steam launch-mode and account dropdowns on custom themes.
- Resolve opaque Nexus dialog colors from the active native theme, including translucent sidebars, and keep fields, options and action buttons readable.
- Fix the missing Backup sidebar label and redundant settings button on themes with positional sidebar rules. Backup now uses one native row: click for settings, hold three seconds to back up, or use the context menu.
- Keep Check for updates, Update / install and confirmation buttons readable during pending actions, with translated progress text and duplicate-click protection. Keep settings headings readable when sidebar and content palettes differ.
- Preserve native navigation and commands, selected Steam account/mode, pending saves, keyboard access, live language changes and Arabic RTL.
- Include the previously completed 1.2.0 revision-10 repairs to backups, history preservation, privacy integration gates, update shutdown, installer compaction, installation checks and source packaging.

This theme-focused candidate defers the additional findings from the separate second audit at the owner's request. Theme tests use isolated fixtures rather than real Steam account switches or user saves. See the validation document for scope.

Validation: 33 default suites on Node 24 and Node 22, nine browser suites, 64 theme/language scenarios and 432 measured updater/text states in isolated fixtures. Source ZIP rebuilds reproduce installer/bridge bytes. No live upgrade or GitHub publication is claimed.
