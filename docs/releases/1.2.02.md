# Hydra Nexus 1.2.02 — local extraction-path preview

This is a personal test build, not a published release. The planned final version is 1.2.2, which the updater orders after 1.2.02. This preview is revision 5 and adds Polish while retaining the extraction-path audit repairs; no automatic installation is performed.

- Add complete Polish (`pl`) translations for all 591 application messages, including the extraction-path plugin. Follow Hydra's selected language, including `pl-PL` and live switches; no separate Nexus language preference.

- Preserve companion files when a download folder is extracted to a different location.
- Keep unused/incomplete archive volumes outside automatic deletion, and delete sources only after native completion succeeds.
- Recover native completion from the durable extracted destination after an interruption, without extracting the files again.
- Reject linked destination folders that redirect writes outside the selected location.
- These are extraction-path repairs; Hydra's existing extraction engine is unchanged.

- Add **Extract path** in Plugins, enabled by default and independently switchable.
- Place **Extract path (Hydra Nexus)** above the download action, using Hydra's native path field and Change button.
- Remember the last folder used for an accepted download, and save each download's choice independently, including queued downloads and restarts.
- Create a game folder inside the selected location; preserve the original download location for torrent resume, seeding and archive removal.
- Find game executables and classic discs in the extracted destination, and open that folder from installer actions.
- Preserve archives on extraction failure; refuse overlapping source/destination folders and unrelated existing output folders.
- Translate the plugin, field, picker and messages into all eight interface languages, including live language changes and scoped Arabic RTL.
- Retain the previous inactive-window video policy, early background startup repair, and removal of the unnecessary zero-radius blur filter.

Disabling the plugin hides the field and uses native extraction for pending/new work. Already extracted files retain their saved discovery location. No HatchZip integration is included.

Validation uses isolated data and native-code/UI fixtures. No real game, Steam account, download or live installation is used. Do not treat this preview as published 1.2.2.
