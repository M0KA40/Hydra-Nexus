# Hydra Nexus 1.2.0

![Invisible Mode — play on your terms](https://raw.githubusercontent.com/M0KA40/Hydra-Nexus/v1.2.0/assets/announcements/invisible-mode-1.2.0.png)

## Invisible Mode — play on your terms

Appear offline in Hydra while keeping your library connected. Game images, the interface and your local progress stay available.

- Enable **Invisible Mode** in Plugins to add its control below **Friends** in your account menu.
- Turn privacy on or off with one click. A bright green check and **On** show when protection is active; a dim icon and **Off** show when it is inactive.
- Pause Hydra presence, chat connections and activity uploads while you play. Private progress stays local after turning the mode off until you explicitly choose **Resume activity sharing**.
- Disable the plugin to turn the mode off and hide its account-menu control.

## Eight interface languages

- Added English, Brazilian Portuguese, Spanish, Russian, Arabic, French, German and Turkish across Nexus settings, tools, help, notifications and application dialogs.
- Follow Hydra's selected language automatically, including changes while the app is open. Unsupported languages fall back to English.
- Added Arabic right-to-left layouts and localized dates, durations and numbers.
- Preserve form drafts, Notes edits, Steam selections and ongoing actions when changing language.

## Steam and Desktop shortcuts

- Fixed existing Hydra Desktop shortcuts skipping the game's saved Steam account switch. The same preparation now runs whether Hydra is closed or already open.
- Existing shortcuts continue to work without recreation and use the game's current settings. Games without a saved Steam account launch normally.
- Prevented competing Play and shortcut requests from switching accounts over each other. Repeated identical requests share one launch; competing requests receive a clear retry message.
- Added localized switching progress, online/offline labels and busy feedback.
- Protected native LaunchBox Desktop launches while a Nexus restore is replacing files.

## In-app updater

- Rebuilt the install-and-restart handoff with a single saved update job and explicit data saving before Hydra closes.
- Fixed Hydra getting stuck during the update restart. Installation starts only after the app closes and the files are available.
- Added a confirmation window using Hydra’s own interface and theme, with clear save, install and restart steps. Download source and SHA-256 are available under **Update details**.
- Repeated clicks share one installation. Expired or cancelled helpers cannot install later, and cached GitHub downloads are checked against the current release before use.
- Preserved checksum verification, verified recovery copies, rollback and a single relaunch. Failed preparation keeps Hydra open.

## Interface and reliability

- Integrated Nexus navigation and the Invisible Mode control into Hydra's native interface, with controls that follow the current theme.
- Fixed the enabled account-menu control being missing when Hydra selected its hosted interface.
- Removed repeated page-wide observation and unnecessary background refreshes from supported native UI paths. Privacy checks now use indexed lookups, batched saves and small status updates.
- Kept private screenshot entries visible in Hydra's local synchronization list while continuing to block their upload.
- Fixed the private-game counter counting a game's local and remote identifiers twice.
- Bundled the Invisible Mode announcement image with the app so it displays inside the update notes without a separate image download or a blocked media URL.
- Preserved native pending achievement records and queued privacy holds across normal shutdown.
- Improved live-language messages, Steam focus, per-game Backup controls and cached PC comparisons.

Your existing Nexus settings, Notes, play history and backups are preserved when updating.

## 1.2.1 — Fixes and improvements

### Theme and interface fixes

- Fixed unreadable Steam launch-mode and saved-account dropdown options on custom themes.
- Improved text, field and dialog contrast on dark, light and translucent themes, including themes with different sidebar and content colors.
- Fixed the missing Backup sidebar label and redundant settings button. Backup now uses one clear row: click to open settings, hold for three seconds to back up, or use the context menu.
- Fixed Check for updates, Update / install and confirmation buttons becoming faded during pending actions. Progress labels remain readable, and repeated clicks cannot start duplicate requests.
- Preserved native navigation, selected Steam settings, pending saves, keyboard access, live language changes and Arabic right-to-left layouts.

### Backup, data and update reliability

- Preserved complete recovery points when save discovery fails, identified partial backups and verified the recovery point used for unchanged results.
- Preserved damaged play-history and Steam-binding files instead of replacing them with empty data.
- Strengthened Steam, Epic and RetroAchievements privacy integration gates. Interrupted store-wide synchronization remains held until activity sharing is explicitly resumed.
- Improved update shutdown handling for new work, late saves and stalled phases, and restored the previous installation when relaunch fails before starting.
- Improved installer compaction and installation verification, and tracked long per-game backup/import operations independently of renderer request timeouts.
- Improved update-recovery retention, source-package selection and long-press handling.

Experimental version 1.2.01 can update to final version 1.2.1. Existing settings, Notes, play history and backups are preserved.
