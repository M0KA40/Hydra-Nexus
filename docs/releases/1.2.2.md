# Hydra Nexus 1.2.2

## Extract path — your games, your destination

- **Choose where your games are extracted.** The new **Extract path (Hydra Nexus)** field appears above the download button when automatic extraction is enabled. Download to one location and extract to another.
- **Your choice is remembered.** Nexus saves the last folder used by an accepted download. Each queued download keeps its own destination, including after a restart. A game folder is created inside the folder you choose.
- **Feels at home in Hydra.** Uses Hydra's native path field and Change button to follow your theme. The Extract path plugin is **enabled by default** and can be disabled in Plugins.
- **Safer destination handling.** Protects existing files, rejects conflicting or linked destinations, checks available space and preserves companion files. Recovery remembers completed extraction before any requested archive cleanup.
- Download locations continue to work with Hydra's resume and seeding features. The extracted game is discovered at its chosen destination.

## Polish language support

- Added **Polski**, bringing Nexus to **nine interface languages** with 591 translated messages in each.
- Follows Hydra's selected language, including live changes. Paths and game names stay unchanged; Arabic RTL and English fallback remain supported.

## Video background fixes and improvements

- Added **Pause video when Hydra is inactive**, enabled by default. Videos pause when Hydra loses focus, is minimized or hidden, then resume from the same position. You can turn this preference off in Themes.
- Low Resource Mode continues to take priority over video playback and blur.
- Fixed the native wallpaper flashing before a custom background appears at startup. A failed background restores the native theme.
- Unified video playback behavior across Nexus and workspace events, and removed the unnecessary filter when blur is set to zero.
- Added clearer guidance for MP4, WebM and MOV backgrounds and codec-dependent playback.

## Updating

**1.2.2 is the official release following the 1.2.02 preview.** It is offered as a newer update to both 1.2.1 and 1.2.02 users.

Your existing Nexus settings, Notes, play history and backups are kept. Download **Hydra_Nexus.bat** below, or use **Settings → Hydra Nexus → Updater**. The source package and **SHA256SUMS.txt** are included with this release.
