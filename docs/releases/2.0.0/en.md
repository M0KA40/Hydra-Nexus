# Hydra Nexus 2.0

Game Storage Manager. Download Finish Actions. Play Activity. And much more. New game-management tools with improvements to plugins, backups, backgrounds, tabs and data protection.

## Game Storage Manager

Browse installed games by drive, free space and measured size; search, sort and filter by last played. Open folders or move selected games after reviewing the destination. Verify copied files before updating paths/removing originals. Uncertain roots and partial scans are clearly identified.

## Download Finish Actions

Choose a notification, Sleep or Shutdown after all queued downloads and enabled extractions complete. Power actions provide 60 seconds to cancel. New work resumes waiting; exiting Hydra cancels the action. Enabling the plugin requires restart, without automatically arming a power action.

## Play Activity

Browse weekly/monthly recaps of recorded playtime, games, active days and available dated achievements. Review earlier periods using Hydra artwork. Control notices from the bell or disable recaps/notices while keeping game-session tracking.

## Improved game statistics

Redesigned the statistics page for each game to show playtime, active days and session history more clearly, with a chart showing playtime by day.

Review each session’s start time, end time and duration, and filter activity by the last 7 days, last 30 days or all time. The statistics button beside playtime opens that game’s statistics directly.

## Plugin library

Enable plugins directly on their cards. Open full settings and consistent visual guides in native Hydra dialogs. Durable new-feature indicators retain acknowledgement. Enabling Invisible Mode activates privacy immediately; later account-menu choices persist.

## Backup improvements

Native per-game profiles show the latest complete point and recovery history. Restore, open folders or extract a copy without replacing saves. Per-game disable keeps older points. Merge Games/Recovery navigation while retaining bulk restore. Collection imports prefer complete backups and validate metadata. Failed restores undo touched metadata while preserving newer untouched values.

## Tabs and backgrounds

Retain game/Catalogue state, results, inputs and scroll across tab changes; pause hidden work and release resources on close. Fix Catalogue returning to the top. Improve video loading/switching and preserve the previous background when a replacement fails.

## Stability and data protection

Preserve damaged settings and achievement files. Protect local achievements during Steam sync and existing Nexus Mods keys on failed replacement writes. Recover from update preparation failures and check helper acknowledgement before exit. Wait for the actual updater result. Invalid hardware-rating caches no longer block bundled references. Improve nine-language coverage, Arabic RTL and theme/native-dialog behaviour.

The approved English update cover is bundled and appears across interface languages. Backup illustrations use one restore line branching to both saves and achievements.

---

Activity cannot reconstruct earlier sessions from lifetime totals. Measured file bytes may differ from disk allocation. Storage moves do not rewrite external launcher registrations or shortcuts. Tabs belong to the current app session. Reapply a compatible Nexus build if a Hydra update replaces its modifications.
