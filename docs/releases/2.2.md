## Nexus Quiet — a redesigned interface, in beta

Nexus Quiet goes beyond a conventional Hydra color theme. It redesigns navigation, Home and game pages, with integrated features that improve everyday browsing. Choose Quiet Slate or Nexus Mint using the circular color selectors in Settings → Themes. Both share the same layout and functionality. This is an initial beta; development and refinement will continue.

## A new Home experience

Home now presents games in a cinematic carousel, with artwork, descriptions and direct navigation. Expanded discovery sections refresh from Steam data and make newer releases easier to browse. The top navigation keeps Hydra's main areas within reach. Discovery uses cached data when available; coverage and freshness depend on Steam availability.

## Redesigned game pages

Game pages now organize information into Overview, Updates, About, Community and Details. Updates brings Steam news and patch notes into Nexus with an internal reader, loading more, manual refresh and offline cached content. Games outside your library open About automatically. Library games open Overview. Compact achievements, readable media and centered review sections make better use of space. Technical cards remain open. This first version will continue to improve.

## Game Page Layout

Choose which game-page sections appear and arrange their order from Plugins. Visibility can apply to library games or all games. Hidden middle sections retain their space; hidden sidebar sections release theirs. Preferences are saved without replacing unrelated controls or drafts.

## Fixes for existing installations

- Fixed older Invisible Mode restrictions that prevented playtime and achievements from reaching the profile until activity sharing was manually resumed. Upgrading resumes native sharing automatically, including a retry when the account session becomes ready. Invisible presence is retained; protected historical screenshots remain protected.
- Fixed updates failing when the executable remained briefly locked after closing Hydra. The updater now retries temporary lock conflicts within a bounded wait and preserves recovery if the lock persists.

Available in all nine supported interface languages. The interface redesign remains beta even though this is the 2.2 application release.
