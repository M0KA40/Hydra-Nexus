# Hydra Nexus 2.3.1

Versión interna de pruebas que continúa la interfaz 2.2 y las mejoras de Draft-2.3.

Una inyección por documento, actualizaciones agrupadas y consultas de descubrimiento progresivamente menos frecuentes. El monitor de logros Steam se cierra al terminar la sesión. Se mantiene la reducción del desenfoque para evaluarla.

Confianza limitada a la aplicación instalada. Nombres y enlaces del archivo se verifican antes de extraer; si no se puede verificar, se conservan los originales. Se corrigen enlaces de notas y ocultación de rutas del registro.

Nexus e instalador muestran 2.3.1. Prueba local sin publicación. Las pruebas aisladas no demuestran el consumo de RAM o CPU de Hydra instalado.

Revisión 2: el instalador limpia sus recursos temporales tras el éxito; conserva fallos y copias de recuperación. Compactación ASAR probada con 5 GiB obsoletos y reparaciones repetidas.
