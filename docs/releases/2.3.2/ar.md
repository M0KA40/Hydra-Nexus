# Hydra Nexus 2.3.2 — المراجعة 7

صفحة Cloud داخلية كاملة بخلفية ثابتة وشعارنا وأغلفة عمودية وحركة دخول. إدارة اللعبة تفتح تحت اسمها، بثلاث مهام واضحة: نسخ الآن، استرجاع من السحابة، وتنزيل نسخة. مصادر الحفظ وإعدادات اللعبة منظّمة بشكل منفصل.

نسخة سحابية أخيرة واحدة لكل لعبة تجمع ملفات الحفظ والإنجازات المحلية المكتشفة. تُرفع النسخة الجديدة ويُتحقق منها قبل استبدال السابقة. ملفات النقل مؤقتة، والنسخ المحلية القديمة الموجودة لا تُحذف. تُحفظ نسخة أمان داخلية قبل الاسترجاع. الإضافة والنسخ التلقائي اختياريان.

الاسترجاع يفحص السحابة ثم يتيح اختيار الألعاب أو الكل، وينزل النسخ ويتحقق منها ويطلب مراجعة صريحة قبل الاسترجاع المتتابع. تحفظ النسخ الجديدة المسارات الأصلية والقابلة للنقل، وتعالج مجلدات مستخدم Windows ومواقع التثبيت المعروفة وتنشئ المجلدات المطلوبة. عند تعذر تحديد الموقع يظهر المسار السابق واختيار وجهة داخل الخطوات. النسخ القديمة دون مسارات تحتاج تحديد وجهة.

إشعار متناسق مع الثيم أثناء النسخ بعد إغلاق اللعبة. يبقى تحذير الفشل أو الانقطاع بعد إعادة التشغيل داخل اللعبة وبجانب Cloud. تحديد كمقروء يخفي التحذير دون ادعاء نجاح النسخ، مع تذكير وخياري النسخ الآن أو مفهوم. أُصلح تكرار أزرار النافذة، وحُدّت طلبات الصور وحُفظت حالة الحقول. الإنجليزية مرجع النصوص مع الحفاظ على الترجمات.

تجربة محلية غير منشورة؛ الاختبارات بملفات وألعاب وسحابة محاكاة، ولا ندّعي اختبار حساب سحابي فعلي أو تثبيت حي. خطة EXE الجديدة مؤجلة.

المراجعة 6: استعادة مسارات الحفظ الإضافية حسب معرّف Steam من نظام 2.1، ومنها مستندات Public وProgramData، دون اشتراط تثبيت اللعبة. يُطابق الكشف أسماء قاعدة الحفظ بمعرّف Steam ويعيد النتيجة للعبة الصحيحة. تُحفظ هذه المسارات بصيغة قابلة للنقل وتُنشأ المجلدات المحذوفة عند الاسترجاع. الفحص غير المكتمل لا يستبدل النسخة السحابية السابقة. يظهر توضيح صريح إذا عُثر على الإنجازات فقط. نافذة نتيجة مؤقتة متحركة لنجاح الاسترجاع أو فشله مع السبب، مع بقاء التفاصيل في الصفحة. مدير النقل يعرض 20 حالة حديثة بحد أقصى مع إعطاء العمليات الجارية الأولوية.

المراجعة 7: نسخ جميع الألعاب المؤهلة بفحص واحد للمكتبة. تُنقل النسخة الجديدة كحزمة مضغوطة واحدة مع التحقق، وتبقى النسخ القديمة قابلة للقراءة. استرجاع اللعبة محصور باللعبة المختارة. شريط تقدم مستمر مع الإلغاء بعد مغادرة Cloud، ونوافذ نتيجة للعمليات المهمة. تُعزل سجلات السحابة التالفة، ويوجد مسار مراجعة لإصلاح الاسترجاع المنقطع، مع ضبط الملفات المؤقتة ونسخ الأمان وحماية نسخ الأجهزة الأخرى من الحذف المتزامن. تشفير اختياري بكلمة مرور للحزم الجديدة؛ احتفظ بها خارج الجهاز. تعرض المكتبة آخر نسخة لكل لعبة، وتُحفظ نسخ الأجهزة والجلسات الأخرى احتياطيًا للأمان. لا نرتب سرعة مزودي السحابة دون قياس. زر الرجوع أسفل الشعار وفوق إجراءات الصفحة مع تدرج متصل للشريط العلوي.
