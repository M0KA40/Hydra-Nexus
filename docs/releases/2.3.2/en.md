# Hydra Nexus 2.3.2 — revision 7

Nexus Cloud has a dedicated internal page, a fixed dark background, Hydra Nexus branding, full portrait covers and staged entry animations. Game management expands under the game name. Three main actions explain the process: Back up now, Restore from cloud, and Download a copy. Backup sources and per-game preferences have separate, clear controls.

Each game has one latest successful cloud backup containing its detected save and local achievement files. A new copy is uploaded and verified before replacing the previous cloud copy. Transfer staging is temporary; earlier user-owned local backups are preserved. Internal safety copies protect files before restoration. Nexus Cloud and automatic backup remain opt-in.

Cloud recovery scans the connected account, lets you choose games or select all, downloads and verifies the selected copies, then requests explicit review before sequential restoration. New backups preserve original and portable save/achievement paths, adapt standard Windows user folders, use known game installations and create required directories. If a location cannot be resolved, the original path and an in-place folder choice are shown. Older backups without saved paths require a destination.

Game-exit backups show a themed progress notification. Failed or interrupted backups leave a durable warning on the Cloud navigation item and the game. Mark as read clears the warning without claiming a successful backup; another reminder offers Back up now or Understood. A successful backup clears the failure.

Native window controls are no longer duplicated. Artwork requests are bounded and cached; large lists are paged, and preference changes preserve focus and drafts. Existing interface translations are retained; English is the copy reference. This is an unpublished local preview. Tests use synthetic games, files and cloud transports; real OneDrive/Dropbox account testing and live installation are not claimed. The separate new EXE installation plan remains deferred.

Revision 6: Restores the additional Steam app-ID save locations used by 2.1, including Public Documents and ProgramData, without requiring an installed game. Manifest detection resolves canonical names by Steam ID and maps results back to the library game. New copies preserve these portable roots and recreate deleted destination folders. Incomplete scans cannot replace a previous complete cloud backup. Achievement-only detection is explicitly identified. Restore completion/failure has a temporary animated result popup with the failure reason; detailed results stay on the page. Transfer Manager is capped at 20 recent states with active work first.

Revision 7: Back up all eligible games with one library scan. Each new backup transfers as one compressed, verified package; older copies remain readable. Per-game recovery is restricted to the selected game. A persistent progress bar includes cancellation after leaving Cloud, and important operations show result popups. Catalog damage is isolated, interrupted restores have a reviewed repair flow, temporary files and safety copies are bounded, and concurrent clients cannot delete one another's backups. Optional password encryption protects new packages; keep the password outside this PC. The library shows the latest copy per game; older copies from other devices or sessions are retained conservatively for safety. Provider speed is not ranked without measurements. Back to Hydra sits below the brand, above the page actions, with a continuous header gradient.
