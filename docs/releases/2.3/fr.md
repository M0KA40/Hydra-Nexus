## Le nouveau Nexus est prêt

Gardez Nexus 2.3 avec cette version de Hydra. Mettez Hydra à jour, puis installez Nexus 3.0 pour Cloud, la nouvelle Activité et les statistiques.

Vos réglages sont conservés. Cette version garde les fonctions de 2.2 sans Nexus Cloud ni la nouvelle Activité. Nexus 3.0 prend en charge la version vérifiée Hydra 4.3.0.
