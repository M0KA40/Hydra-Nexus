# Hydra Nexus 3.0 revision 2 — Cloud notification and memory correction

The manual/automatic notification split from the approved Activity source was lost when the r8 recovery-entry fix was merged into 3.0. Restored that split without reverting the r8 stale-review protection. Automatic game-exit operations use the bottom status bar; manual operations keep floating progress/result cards. Durable failure warnings remain.

Large offline tool archives and the save-location manifest were permanent base64 JavaScript literals. They are now separate ASAR binary resources, read only when provisioning/scanning, with the same pinned hashes and offline availability. Existing verified Rclone is reused rather than unpacked again.

An isolated Node 24 fixture parsing/loading the same modules measured retained JS heap overhead at 188.78 MiB before and about 5.93 MiB after; the bridge shrank from 63.32 to 2.37 MiB. These are bundle/main-module measurements, not total live Hydra RAM or a promise about every process. No live Hydra process was available to measure in this run.

A 20-cycle headless Cloud open/close probe also caught detached animated panels. Cancelling only the closing screen’s own animations keeps motion unchanged while allowing cleanup. Before that cleanup, the probe grew from 666 to 10,964 DOM nodes and 42 to 137 event listeners. With cleanup, it stayed at 124 nodes and 37 listeners across 20 cycles; JS heap moved about 0.074 MiB. This checks that flow, not every possible application leak.

Focused notification tests cover automatic running/success/failure without popups, native bottom feedback/focus retention, manual cards and persistent warnings. Pinned offline provisioning, provider safety and native install/repair/rollback checks passed on isolated fixtures. No real saves/accounts or installed Hydra were modified. No Arabic/RTL review or corrections were performed, per owner scope.

Original Release remains immutable. New candidate is Release-r2; visible version remains 3.0 and internal revision is 2. Nothing published.
