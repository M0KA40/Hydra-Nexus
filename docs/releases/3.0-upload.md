# Publishing Hydra Nexus 3.0

Prepared locally; not published. Owner approval to begin uploading is separate.

Create numeric tag `v3.0` as the stable Latest release, with revision marker
`<!-- HYDRA_NEXUS_REVISION 2 -->` in the English release body. Use the body from
`docs/releases/3.0.md`. Keep these four asset names unchanged:

- `Hydra_Nexus.exe`
- `Hydra-Nexus-3.0-source.zip`
- `Hydra-Nexus-3.0-release-notes.json`
- `SHA256SUMS.txt`

Use the allowlisted source tree from the source ZIP for repository changes. Do not
upload the workspace, development/verification folders, test profiles, native
Hydra chunks, `dist/` contents as a whole, the BAT intermediate or preview renderer.
The new feature artwork and update cover are included in the source tree.

After explicit upload approval, check the uploaded EXE checksum and the public
release asset names. Future EXE updates depend on these stable names. Local
fixture acceptance does not establish real provider OAuth, a real new-PC restore
or live friend-account privacy behavior. Cloud remains BETA.
