# Hydra Nexus 3.0

## Nexus Cloud · BETA
Back up supported game saves and local achievement files to your own Dropbox or OneDrive account, in the NexusCloud folder. Connect one provider at a time through the browser; no sync app is required. Authorization is encrypted locally. Scan games, review detected files or add a save folder manually. Back up one game or all eligible games; excluded games are skipped. Optional automatic backup runs after a game closes, with persistent feedback in the bottom status bar and retry details after restart.

Each game uses one compressed, verified package. Failed or partial uploads are not reported as successful. The library shows the latest successful copy; older copies from other devices or sessions may remain for safety and use extra space. Existing local backups are preserved. Optional password encryption protects new packages, not basic catalog identity; keep the original password outside this PC.

On another PC, connect the same account and choose Restore from cloud. Select games, download and verify, review the destinations and confirm explicitly before replacement. Known Windows folders and installation locations adapt to the new device; unresolved or legacy paths require manual selection. Recovery creates missing folders and safety copies before writing. Games must remain closed. Download a copy is also available without replacing local saves. A persistent transfer bar supports cancellation; a restore finishes the current game before skipping the rest. Interrupted recovery has a reviewed repair flow, and damaged catalog entries are isolated. Disconnecting removes local authorization, not cloud copies; switching providers does not transfer them.

BETA detection depends on supported save locations; a manual source is available. Restoring local files does not unlock Steam or Epic achievements. Cloud is turned off once on the first rollout startup, preserving provider data and copies. Later choices remain saved.

## Play Activity and game statistics
A cinematic Activity view with game artwork, colored 3D icons, playtime, sessions and achievements. Browse weekly, monthly or custom periods, then select a day, game or session for details. Recap notifications match the new design without stealing focus. Game statistics have clearer cards, colored indicators, readable charts, better theme contrast and game backgrounds. Preference changes preserve fields, focus and scroll.

## Invisible Mode
A translated activation explanation requires explicit agreement before starting a game. Previously active mode is turned off once so you can review the new behavior; plugin availability is preserved. Local library tracking continues, while active Invisible Mode blocks public activity and profile-hour writes. Profile hours may pause, and turning the mode off may resume pending uploads. Already sent activity cannot be recalled.

## General improvements
Compatibility improvements for Hydra 4.3.0, fewer redundant UI/discovery updates, improved Steam achievement watcher lifetime, stronger archive path checks, corrected notes links and redacted sensitive log paths. All nine languages and Arabic RTL remain supported. Activity stays on by default while respecting previous opt-outs; its small update marker clears after visiting. Cloud keeps its BETA badge.
