# Hydra Nexus 3.0

## Nexus Cloud · BETA
Sauvegardez les parties et succès locaux pris en charge dans le dossier NexusCloud de votre compte Dropbox ou OneDrive. Connectez un service à la fois via le navigateur, sans application de synchronisation ; l’autorisation est chiffrée localement. Analysez les jeux, vérifiez les fichiers ou ajoutez un dossier manuellement. Sauvegardez un jeu ou tous les jeux admissibles ; les jeux exclus sont ignorés. La sauvegarde automatique facultative intervient après la fermeture, avec suivi dans la barre inférieure et erreurs consultables après redémarrage.

Chaque jeu utilise un paquet compressé et vérifié. Un transfert partiel n’est pas un succès. La bibliothèque présente la dernière copie réussie ; des copies d’autres appareils ou sessions peuvent rester par sécurité et occuper plus d’espace. Les sauvegardes locales existantes sont conservées. Le chiffrement facultatif protège les nouveaux paquets, pas l’identité de base du catalogue ; gardez le mot de passe initial hors de ce PC.

Sur un autre PC, connectez le même compte et choisissez la restauration cloud. Sélectionnez les jeux, téléchargez et vérifiez, examinez les destinations et confirmez avant remplacement. Les dossiers Windows et installations connus sont adaptés ; les chemins inconnus ou anciens demandent une sélection manuelle. Les dossiers absents et copies de sécurité sont créés. Gardez les jeux fermés. Vous pouvez aussi télécharger une copie sans remplacer les fichiers. Annuler une restauration termine le jeu courant et ignore les suivants. Une réparation contrôlée traite les interruptions ; les entrées corrompues sont isolées. Déconnecter supprime seulement l’autorisation locale ; changer de service ne transfère pas les copies.

BETA : la détection dépend des emplacements pris en charge, avec ajout manuel possible. Les fichiers locaux ne débloquent aucun succès Steam/Epic. Cloud est désactivé une seule fois au premier démarrage, sans perdre compte ni copies ; les choix suivants sont conservés.

## Activité, statistiques et mode invisible
Nouvelle Activité avec jaquettes, icônes 3D colorées, temps, sessions et succès. Périodes hebdomadaires, mensuelles ou personnalisées et détails par jour, jeu et session. Les récapitulatifs ne prennent pas le focus. Statistiques plus lisibles, meilleur contraste et arrière-plans de jeux ; les préférences préservent champs et défilement.

Le mode invisible exige un accord traduit avant de lancer le jeu et se désactive une fois pour révision, tout en conservant la disponibilité du plugin. Le suivi local continue ; l’activité publique et les heures du profil sont bloquées. Le désactiver peut reprendre les envois en attente ; les activités déjà envoyées ne sont pas retirées.

## Améliorations générales
Compatibilité Hydra 4.3.0, moins de rafraîchissements redondants, meilleur cycle des observateurs Steam, contrôle des chemins d’archives, liens corrigés et chemins sensibles masqués dans les journaux. Neuf langues et RTL préservés. Activité respecte les désactivations antérieures ; son indicateur disparaît après visite. Cloud conserve BETA.
