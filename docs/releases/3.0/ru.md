# Hydra Nexus 3.0

## Нативный EXE-установщик
Полный установщик Windows с выбором языка, собственным окном и значком панели задач и повторным открытием Hydra. Будущие обновления используют проверенные EXE. Известные старые компоненты заменяются с сохранением настроек.

## Nexus Cloud · BETA
Сохраняйте поддерживаемые сохранения и локальные достижения в папке NexusCloud своего Dropbox или OneDrive. Подключайте один сервис через браузер, без приложения синхронизации; авторизация шифруется локально. Сканируйте игры, проверяйте файлы или добавляйте папку вручную. Копируйте одну игру или все подходящие; исключённые игры пропускаются. Автокопирование по желанию запускается после закрытия игры, с прогрессом внизу и сохранением ошибок после перезапуска.

Для игры создаётся один сжатый проверенный пакет. Частичная загрузка не считается успехом. Библиотека показывает последнюю успешную копию; старые копии других устройств или сеансов могут сохраняться для безопасности и занимать дополнительное место. Старые локальные копии сохраняются. Шифрование паролем защищает новые пакеты, но не основную идентификацию каталога; храните исходный пароль вне этого ПК.

На другом ПК подключите тот же аккаунт и выберите восстановление из облака. Выберите игры, скачайте и проверьте, просмотрите назначения и явно подтвердите замену. Известные папки Windows и пути установки адаптируются; старые или неизвестные пути выбираются вручную. Создаются отсутствующие папки и страховочные копии. Игры должны быть закрыты. Можно скачать копию без замены файлов. Отмена завершает текущую игру и пропускает остальные. Для прерванного восстановления есть проверяемое исправление, повреждённые записи изолируются. Отключение удаляет только локальную авторизацию; смена сервиса не переносит копии.

BETA: обнаружение зависит от поддерживаемых путей, доступно ручное добавление. Локальные файлы не открывают достижения Steam/Epic. При первом запуске Cloud отключается один раз с сохранением аккаунта и копий; дальнейший выбор сохраняется.

## Активность, статистика и невидимый режим
Новая активность с обложками, цветными 3D-значками, временем, сеансами и достижениями. Недели, месяцы и произвольные периоды с деталями по дню, игре и сеансу. Итоги не перехватывают фокус. Статистика получила понятные карточки, графики, контраст и игровые фоны; настройки сохраняют поля и прокрутку.

Невидимый режим требует переведённого явного согласия до запуска игры и отключается один раз для ознакомления, сохраняя доступность плагина. Локальный учёт работает, публичная активность и запись часов профиля блокируются. Выключение может возобновить ожидающие отправки; ранее отправленное не отзывается.

## Общие улучшения
Совместимость с Hydra 4.3.0, меньше повторных обновлений, улучшенный жизненный цикл наблюдателей Steam, проверка путей архивов, исправленные ссылки и скрытие чувствительных путей в логах. Сохранены девять языков и RTL. Активность учитывает прежний отказ; метка исчезает после посещения. У Cloud остаётся BETA.
