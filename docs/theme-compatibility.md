# Theme compatibility

Nexus uses Hydra's native modal, buttons, navigation and layout styles. Plugin settings open in the native dialog. Text, fields and notices resolve readable colors against the active theme; native controls keep their keyboard behavior. Live language or theme changes retain unsaved drafts and pending controls.

Custom image/video backgrounds replace the wallpaper while retaining theme controls and typography. Reset restores the theme background. Video decoding depends on the installed codec. See [features](features.md).

Browser acceptance uses eight representative dark, light, translucent and override-heavy theme profiles. These checks do not imply every third-party theme has been tested. Report the Hydra and Nexus versions, theme name and a screenshot if a theme causes a problem. See [verification](verification.md) for test setup.
